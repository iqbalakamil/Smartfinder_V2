📸 Instagram Locator & Social POI

Layer Instagram Locator NONAKTIF

Klik toggle ke ON untuk menampilkan marker lokasi Instagram terdeteksi di koordinat peta.

Langkah Instagram Locator
  1. Klik Auto-get Cookie via Browser lalu login ke Instagram di Chrome.
  2. Koordinat IG akan mengikuti menu input lokasi utama, lalu bisa diubah atau dikosongkan jika ingin cari area lain.
  3. Pilih mode pencarian: Normal Search, Fuzzy Search, atau Perumahan Search.
  4. Klik Search Locations untuk mulai mencari lokasi.
📍 Koordinat Target Area (Sinkron dari Input Lokasi): - Kalau kolom ini kosong, sistem akan pakai koordinat dari menu input lokasi. Isi manual hanya untuk pencarian area lain.
Klik Auto-get Cookie via Browser untuk membuka Chrome & login ke Instagram. Cookie akan terisi otomatis dan dapat Anda hapus / edit kapan saja.
Grid search memindai area secara sistematis untuk menemukan lokasi perumahan.
Ikuti step di atas: cookie -> koordinat -> mode pencarian -> cari.
